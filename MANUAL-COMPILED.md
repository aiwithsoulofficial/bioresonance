## 1. OVERVIEW - TREATMENT FLOW

The treatment follows this sequence (Figure 1.1):

**Blockages -> Energy Stabilisation -> Strains -> Constitutional Support -> Detoxification -> Deficiencies**

Advanced Techniques (combination testing, dental testing, five element testing, Kurzbak testing, loop testing, second channel) can be applied throughout.

### Session Protocol Order
Each session addresses these elements as determined by testing:
1. Treatment of blockages, including inversion from metals
2. Energy stabilisation
3. Detoxification
4. Treatment of allergies or strains
5. Treatment of deficiencies
6. Constitutional support as needed

### Key Rules
- Within a given session, blockages and basic therapies must be treated FIRST
- Provide at least one detoxification program prior to treating allergies or strains
- Once a detox program has been delivered, the number of strains treated can be determined by available time, with a maximum of six strains in any one session
- Detoxification priority alters through the course of treatment - these programs need to be tested for and at least one delivered at each session
- For follow-up treatments, each element is the same as for initial treatments with modifications:
  - Blockages and strains (test on 191), with strains previously treated and test for any not yet treated
  - Energy stabilisation (basic therapy) is re-tested and treated according to test findings
  - Detoxification priority alters through treatment course

## 3. SPECIAL POPULATION PROTOCOLS

- Program A-trace covering 1000 can be effective in pregnancy
- Precautions should be noted, treat with care

- Provocation of strains is not recommended

- Treatments can be given with care taken not to release toxins that will then be passed via the milk to the baby

- More time should be spent on basic, meridian and constitutional therapies

- Detoxification programs are not recommended to protect the baby from toxin release
- Provocation of strains is not recommended

### Hyper-sensitive / Immune Disorders
- Individual strains and deficiencies that have led to the targeted organ or system also need to be checked
- Expect to find many strains from candida, chemicals, metals, moulds and yeasts, parasites, vaccinations and viruses as well as masked allergies to milk proteins (beta-lactoglobulin and casein) and to gluten
- Treatment priorities: focus on underlying causes as well as providing symptom relief - see Auto-immune chapter in Complex Conditions
- More time should be spent on basic, meridian and constitutional therapies before creating for strains. As a basic program, do not use program 133 in the first visit; instead, use program 130
- The strains most likely to be masked will be milk protein and gluten
- Fewer strains should be treated in each session, with more time instead given over to detoxification programs
- The immune system should not be stimulated with programs such as Immune boost, Immunodeficiencies, Resistance (to increase powers of), or Thymus activation. For hyperthyroid conditions, the Thyroid activation program should not be used
- Many sufferers will have masked allergies to metals
- Vaccinations and childhood illnesses should be treated last
- If any clients have a reaction while being treated, apply program 127 (an H therapy program with the lowest amplification) or program 128 (H + Di therapy with lowest amplification). Ensure water is given.

### Organ Transplant Recipients and Haemophilia
- Immune system is on immuno-suppressant drugs - not stimulated
- Using Bicom with clients who have had organ transplantation is NOT recommended by Regumed
- DMI (Schumann waves) cannot be used with haemophilia (haemorrhaging disorders)

## 4. INFECTION CONTROL

### Collecting blood for treatment
- Use single use lancets
- Wear gloves when taking blood
- Use alcohol wipes on the finger after blood has been taken
- Place the lancet into a sharps container
- Wash hands after removing gloves

### Collecting stool or urine
- Provide clients with a glass, disposable container
- Wear gloves when handling containers
- Do not open or transfer the contents of containers
- Dispose of containers without compromising their seal

### Collecting saliva
- Place saliva into a glass beaker
- Following use, spray this container with disinfectant and rinse
- Place the disinfected glass beaker into a container of sterilising solution
- Change the sterilising solution daily
- Alternatively, use single-use disposable glass test tubes
